# 恐龙快跑（Dino Run）使用手册

一个还原 Chrome 浏览器断网小恐龙的网页小游戏。纯前端实现，单个 HTML 文件，无需安装任何依赖。

## 一、如何运行

### 方式 1：直接打开（最简单）
用浏览器直接打开 `index.html` 文件即可开始游玩。

### 方式 2：本地服务器（推荐）
在项目目录下执行：

```bash
cd /home/ubuntu/workspace/dino-game
python3 -m http.server 8000
```

然后用浏览器访问：<http://localhost:8000/>

> 端口 8000 若被占用，可改成其它端口，例如 `python3 -m http.server 8080`。

## 二、操作方法

| 操作 | 按键 / 手势 | 说明 |
| --- | --- | --- |
| 开始游戏 | `空格` / `↑` / `W` / 点击画面 | 首次按下即开始 |
| 跳跃 | `空格` / `↑` / `W` | 落地后可再次跳跃 |
| 下蹲 | `↓` / `S` | 空中按下会快速下落落地 |
| 重新开始 | `空格` / `回车` / 点击画面 | 游戏结束后生效 |
| 音效开关 | 右上角 🔊 图标 | 点击切换开 / 关 |

## 三、游戏规则

- 控制恐龙一直向前奔跑，躲避沿途的**仙人掌**（地面）和**翼龙**（空中）。
- 存活越久，奔跑速度越快，难度越高。
- 每跑过一段距离得 1 分；成功越过障碍还会额外加分。
- 撞到障碍即游戏结束，屏幕上会显示本次得分与历史最高分。
- 最高分会自动保存在浏览器本地（`localStorage`），下次打开仍然保留。

## 四、特性说明

- **像素风格**：恐龙奔跑双脚交替动画、仙人掌、扇动翅膀的翼龙、飘动的云和地面石子。
- **昼夜循环**：游戏进行约 40 秒会自动在白天 / 夜间主题间切换。
- **音效**：使用 Web Audio 实时合成，无需外部音频文件。
- **自适应**：自动适配高分屏（DPR），支持键盘与触屏操作。
- **切后台暂停**：切换到其它标签页时会自动暂停，避免回来后角色穿模。

## 五、常见问题

- **没有声音？** 浏览器要求用户先与页面交互才能播放音频，开始游戏（按一下跳跃键）后即可听到；也可检查右上角音效是否处于 🔇 状态。
- **想调整难度？** 编辑 `index.html` 中的以下常量：
  - `SPEED_START`：初始奔跑速度（默认 `5.2`）。
  - `SPEED_MAX`：最高奔跑速度（默认 `13`）。
  - `GRAVITY`：重力加速度（默认 `0.75`），越大跳跃下落越快。
  - `JUMP_V`：起跳初速度（默认 `-13.5`），越大跳得越高。
- **想清除最高分？** 在浏览器开发者工具中执行 `localStorage.removeItem("dinoHigh")`。
